# 1C Database Bridge

Локальный мост для безопасной диагностики информационной базы 1С.

## Цель

Связать локальную 1С-базу `localhost\\roz2026` с инструментами диагностики без публикации базы и учетных данных в GitHub.

## Принцип работы

```
ChatGPT / GitHub
       |
       v
  исходный код
       |
       v
Windows 11 — локальный агент
       |
       v
1C:Enterprise — localhost\\roz2026
       |
       v
Розница 2.3 / PostgreSQL
```

## Безопасность

- GitHub не содержит пароль базы данных.
- На первом этапе операции только для чтения.
- Удаление данных будет добавлено только после резервного копирования и отдельного подтверждения.
- Прямое удаление строк из PostgreSQL не используется.

## Структура

- `agent/` — локальный Windows-агент.
- `1c/source/` — исходники внешней обработки 1С.
- `1c/epf/` — собранные EPF-файлы.
- `scripts/` — PowerShell-скрипты.
- `config/` — примеры локальной конфигурации без секретов.
- `docs/` — документация.

## Текущая база

Информационная база 1С: `localhost\\roz2026`.

**Важно:** реальные пароли, дампы production-базы и персональные данные в репозиторий не помещаются.
