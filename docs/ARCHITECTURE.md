# Архитектура

На первом этапе проект не публикует 1С наружу.

Локальный агент на Windows выполняет строго определенные операции с информационной базой. GitHub используется для хранения исходного кода, версий и внешних обработок.

Этапы:

1. Read-only диагностика.
2. Инвентаризация объектов и документов.
3. Резервное копирование.
4. Анализ зависимостей перед очисткой.
5. Отдельный режим очистки с подтверждением.
6. Контрольная проверка базы.

Прямые DELETE/UPDATE в таблицах PostgreSQL для объектов 1С не применяются.
